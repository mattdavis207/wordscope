Wordscope Browser Extension

This repository contains the source code for the Wordscope browser extension. Wordscope is a tool designed to help users understand unfamiliar words directly on any webpage by providing quick definitions, synonyms, antonyms, pronunciation, and contextual explanations. The extension is built with Plasmo, React, and TypeScript, and is structured for clarity, modularity, and long-term maintainability.

The project includes all components for the extension, such as the popup interface, the in-page definition bubble, API integration for multiple dictionary sources, user settings, and logic for capturing selected text on webpages. It is intended to simplify the reading and research process by allowing users to access language information without leaving the page.

This repo serves as the development workspace for Wordscope, containing the complete implementation of its UI, content scripts, background logic, configuration, and build pipeline. It also includes styling, shared components, and utilities used throughout the extension.
